**ACTIVITY -1** 



How the Internet Works 

Students simulate the interaction between a browser, server, and database to understand how requests are processed and responses are returned. 



Answer: The Internet is a global network that allows computers and devices to communicate with each other. When we access a website, the browser sends a request to a web server using protocols such as HTTP or HTTPS. The server receives the request, processes it, and communicates with the database if required. The database stores and retrieves the requested information. The server then sends the required response back to the browser, which displays the information to us.



Basic flow:



User → Browser → Server → Database → Server → Browser → User



Through this activity, we understood the role of the browser, server, and database and how they work together to deliver information over the Internet.



**ACTIVITY-2**



&#x20;Logic Building Challenge 

Students solve progressively complex logical problems using flowcharts and pseudocode before implementing them in code.



Answer: Logic building is the process of developing a systematic approach to solve a problem. Before writing a program, we can understand the problem, identify the required inputs and outputs, and develop a solution using pseudocode and flowcharts.



A flowchart represents the steps of a solution using graphical symbols, while pseudocode represents the solution using simple, programming-like statements without following the syntax of a particular programming language.



**PSEUDO CODE :**



&#x20;START

Input number N

IF N % 2 == 0

&#x20;   Display "Even Number"

ELSE

&#x20;   Display "Odd Number"

END IF

STOP

**ACTIVITY-3**



Real-world Scenario Mapping 

Students identify common applications they use daily and map their frontend, backend**,** and database components



Answer:Modern applications generally consist of three major components: frontend, backend, and database.



Frontend: It is the user interface through which we interact with an application. It includes buttons, forms, menus, images, and other visible elements.

Backend: It handles the application logic, processes requests, performs operations, and communicates between the frontend and database.

Database: It stores and manages application data such as user information, products, orders, messages, and transactions.



**EXAMPLE:**



Frontend:Food menu, restaurant list, cart, order button

Backend: Login, order processing, payment and delivery processing

Database:User details, restaurant details, food items and order details
